HTML 편집 실습 페이지

텍스트를 더블 클릭하거나 요소를 선택한 뒤 오른쪽 패널에서 문구와 스타일을 수정하세요.

링크 주소를 변경하세요

표 · 작업 목록

셀을 클릭하면 셀 문구를 수정할 수 있습니다. 내부 문구가 선택되면 ‘상위 요소 선택’으로 셀을 선택하세요.

작업 담당자 상태
랜딩 페이지 문구 정리 김민지 진행 중
디자인 검토 이준호 검토 대기
HTML 저장 및 공유 박서연 완료

코드블록 · 인사 함수

코드를 더블 클릭하면 화면에서 직접 편집할 수 있습니다. Tab으로 들여쓰기하고 Ctrl+Enter로 적용하세요. 

function greet(name) {
  return "안녕하세요, " + name;
}

console.log(greet("HTML Studio"));
// <strong> 같은 태그 문자열도 코드로 유지됩니다.

칩 · 상태와 분류

칩의 문구를 수정하고, 상위 요소를 선택해 배경색·테두리·모서리를 변경하세요. 아이콘은 유지됩니다.

레이블 · 입력 항목과 안내

레이블을 선택해 문구와 스타일을 수정하세요. 입력 항목과의 연결은 유지됩니다.
